# PTIT LMS - Extension Unlock (v2.2.0)
tool được vibecode 98% :D

Tiện ích mở rộng và UserScript mở khóa tính năng tua video trên hệ thống LMS PTIT.

 **Phát triển bởi:** [GLGT67](https://github.com/GLGT67)

## 🎯 Các Tính Năng Nổi Bật

1. **Thanh công cụ HUD tiện lợi nổi trên video:**
   - **⏪ -10s / ⏩ +10s:** Tua nhanh hoặc lùi 10 giây.
   - **⏩ +1m:** Tua nhanh 1 phút.
   - **⚡ 2x / 🚀 5x:** Tăng tốc độ phát video.
   - **🎯 Xong:** Nhảy thẳng đến gần cuối video để hoàn thành bài giảng tức thì.
2. **Phím tắt điều khiển nhanh:**
   - Phím `→` / `←`: Tua tới / lùi 5 giây.
   - Phím `]` / `[` hoặc phím `+` / `-`: Tăng / giảm tốc độ xem (1x đến 16x).
3. **Bảng thông báo (Toast HUD):**
   - Hiển thị trực quan tốc độ và thời gian tua góc trên màn hình.


## 🛠 Hướng Dẫn Cài Đặt

### Cách 1: Nạp qua Chrome Extension (có hỗ trợ các trình duyệ sử dụng extension của chormimum)
1. sau khi tải xong, unzip file.
2. Mở Chrome / Edge / Cốc Cốc, truy cập: `chrome://extensions/`
3. Bật công tắc **Chế độ cho nhà phát triển (Developer mode)** ở góc trên cùng bên phải.
4. Bấm vào nút **Tải tiện ích đã giải nén (Load unpacked)** và chọn file PTIT-LMS-EXTENSION-UNLOCK(nằm ở trong file đã được giải nén).
5. Truy cập trang bài giảng trên [LMS PTIT](https://lms.ptit.edu.vn/), bấm **F5** để kích hoạt!

P/s nếu không tải được có thể hỏi AI, hoặc liên hệ với tôi nếu bạn đủ rảnh.
