## Hướng Dẫn Cài Đặt

### Cách 1: Nạp qua Chrome Extension (hỗ trợ Chrome, Edge, Cốc Cốc, Brave...)
1. Tải file `PTIT-LMS-EXTENSION-UNLOCK.zip` về và giải nén.
2. Mở trình duyệt, truy cập: `chrome://extensions/`
3. Bật công tắc **Chế độ cho nhà phát triển (Developer mode)** ở góc trên bên phải.
4. Bấm nút **Tải tiện ích đã giải nén (Load unpacked)** và chọn thư mục `PTIT-LMS-EXTENSION-UNLOCK` (nằm trong thư mục đã giải nén)/ hoặc kéo thẳng thư mục đã giải nén vào trang web.
5. Truy cập [LMS PTIT](https://lms.ptit.edu.vn/) hoặc [S-Link](https://slink.ptit.edu.vn/), bấm **F5** để dùng!

### Cách 2: Dùng qua Tampermonkey / Violentmonkey (UserScript)
- Cài extension Tampermonkey hoặc Violentmonkey.
- Tạo script mới và dán toàn bộ nội dung file `workspace/ptit_lms_unlock.user.js` vào rồi lưu lại.
